--------------------------------------------------------------------------------
1. WHAT THE PRODUCT IS
--------------------------------------------------------------------------------
LocalPersona is a Tauri 2 desktop app (Rust backend + vanilla JS frontend)
for creating and chatting with rich AI personas powered by LOCAL GGUF models
via llama.cpp "llama-server" (external child process).

Principles:
  - Local ownership: characters, chats, knowledge are real user-owned files
  - Offline / no cloud accounts / no telemetry
  - Depth over shallow companion apps
  - Inference is external (manage llama-server; do not embed weights)
  - Fail closed on data integrity (no silent corruption / empty assistant saves)

NOT in product (RC):
  - Bundled GGUF models
  - Bundled llama-server binary
  - Live token streaming UI (frozen off)
  - Message edit / branch
  - AR / social / geolocation (FUTURE_VISION only)

5. CRITICAL CONTRACTS
--------------------------------------------------------------------------------
Identity (must not regress):
  conversation_id = UUID under conversations/
  character_id    = characters/{id}.json + RAG
  speaker_id      = "user" for user message attribution ONLY
  Never load character file "user.json" from speaker_id.

Compose:
  non-empty system_prompt => full override
  else mode + name + personality + scenario + user role + writing + greeting
  then optional RAG knowledge block

Inference (shared helpers for send + regenerate):
  resolve_character_id_for_inference
  inference_token_budget (GGUF ctx * 0.82 or 8192)
  load_history_for_inference
  compose_system_with_rag
  post_chat_completion (stream:false, sampling clamped)
  append_message; reject empty model content
  check_arena_reset

Arena (LLM + Voice):
  300 requests OR 45 minutes uptime
  memory_pressure can trigger reset
  last_reset_reason stored for Diagnostics

Streaming: OFF for RC (settings toggle disabled)

Frontend must pass:
  conversation_id: currentConversationId
  character_id: active character
  temperature / max_tokens / top_p from settings
